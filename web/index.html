local startTime = reaper.time_precise()

function check_stop()
  local elapsed = reaper.time_precise() - startTime
  if elapsed >= SWEEP_LEN_SEC then
    reaper.Main_OnCommand(1016, 0) -- Transport: Stop
    local nextPos = endTime + GAP_SEC
    reaper.SetEditCurPos(nextPos, true, false)
    msg(string.format("⏹ STOPPED TAKE #%02d. Advanced cursor to %.1fs", takeIdx, nextPos))
  else
    reaper.defer(check_stop) -- Loop with REAPER GUI tick (120Hz)
  end
end

reaper.defer(check_stop)

Why this matters: In REAPER, calling Lua's native os.execute("sleep") freezes the application thread, causing audio dropouts and crashing the DAW. reaper.defer() schedules the check on REAPER's internal 30Hz–120Hz message pump, maintaining full audio buffer streaming while timing the take to the millisecond.

🧠 PyTorch Forward Pass Flow Parametric WaveNet
1. Audio Input Tensor: x[B, 1, T]
2. Knob Vector: params[B, 5] (Gain, Bass, Mid, Treble, Master)
↓ Knob Conditioning Linear Projection
3. Parameter Embedding: cond[B, C, T] (Broadcast across time)
↓ Channel Concatenation: torch.cat([x, cond], dim=1)
4. Dilated Residual Conv Layers (Receptive field ≥ 4096 samples)
↓ Gated tanh * sigmoid activations
5. Modeled Output Waveform: y_hat[B, 1, T]
Continuous Interpolation:

Because the neural network is trained on a Latin Hypercube spread of knob positions, it learns a continuous multidimensional manifold. You can set the virtual gain knob to 5.372 and the network generates accurate harmonic saturation even though you only sampled at discrete intervals!

📐 Mathematical Objective & Loss Function Multi-Scale STFT
1. Error-to-Signal Ratio (ESR Loss)
$$\mathcal{L}_{\text{ESR}} = \frac{\sum_{t} (y[t] - \hat{y}[t])^2}{\sum_{t} y[t]^2 + \epsilon}$$

Penalizes discrepancies in the raw time-domain waveform. This preserves pick attack, transients, and phase alignment.

2. Multi-Scale Spectral Loss (Frequency Domain)
$$\mathcal{L}_{\text{spec}} = \frac{1}{M} \sum_{m=1}^{M} \left( \|\log |S_m(y)| - \log |S_m(\hat{y})| \|_1 \right)$$

Calculates Short-Time Fourier Transforms (STFT) across multiple FFT window sizes (2048, 1024, 512, 256, 128 samples). This ensures harmonic overtone profiles and tube sag sound authentic across both bass thumps and high-frequency string sparkle.

3. Parametric WaveNet & CatMLP DSP Class Architecture

5-dimensional continuous knob projection concatenated with causal dilated Conv1D channels.

classDiagram
    class ContinuousKnobVector {
        +float gain [0.0 - 1.0]
        +float bass [0.0 - 1.0]
        +float mid [0.0 - 1.0]
        +float treble [0.0 - 1.0]
        +float master [0.0 - 1.0]
        +to_tensor() Tensor[B, 5]
    }

    class CatMLP_Conditioner {
        -Linear fc1 (5 -> 32)
        -ReLU act1
        -Linear fc2 (32 -> 64)
        -ReLU act2
        -Linear fc3 (64 -> latent_channels)
        +forward(params) Tensor[B, C, 1]
    }

    class DilatedConv1D_Block {
        -Conv1d dilated_conv (dilation=2^L)
        -Tanh gated_tanh
        -Sigmoid gated_sigmoid
        -Conv1d residual_conv
        -Conv1d skip_conv
        +forward(x, condition) Tuple[res, skip]
    }

    class ParametricWaveNet {
        +CatMLP_Conditioner conditioner
        +List~DilatedConv1D_Block~ conv_layers
        +Linear output_head
        +forward(audio_x, knob_params) Tensor[B, 1, T]
        +compute_loss(y_true, y_pred) Tuple[esr_loss, stft_loss]
    }

❓ Frequently Asked Architectural Questions Technical FAQ
Q: Why 48kHz 24-bit PCM instead of 44.1kHz?
Neural Amp Modeler's DSP core and modern audio plugin standards (VST3/AU/LV2) are locked to 48kHz. Training on 44.1kHz requires real-time sinc interpolation which introduces high-frequency aliasing artifacts in the neural weights.
Q: Can I run this Lua script on Windows REAPER?
Yes! Cockos REAPER bundles Lua 5.3 natively across Windows, Linux, and macOS. The script uses pure ReaScript API commands (reaper.Main_OnCommand, reaper.defer) without any OS-specific shell dependencies.
Q: How does the final .nam file load into a plugin?
Steven Atkinson's official open-source NAM VST3/AU plugin natively reads parametric models. When loaded, it automatically creates 5 sliders for Gain, Bass, Mid, Treble, and Master right on the GUI.
Q: Can this model run on hardware (e.g. Raspberry Pi)?
Yes! Using nam-core compiled in C++17 with NEON SIMD optimizations, a Raspberry Pi 5 runs standard WaveNet models with less than 2.1ms roundtrip latency.
